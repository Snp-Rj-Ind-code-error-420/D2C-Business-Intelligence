# Streamlit theme options

Each folder contains a ready-to-use `.streamlit/config.toml` theme. Copy one option's `config.toml` into your project's `.streamlit/` folder.

Only one theme can be active at a time. Restart Streamlit after changing it.

## Options
### 01 Minimal Light
Minimal Light — clean SaaS
Bright white canvas, soft neutral surfaces, teal accent. Lowest visual noise.

### 02 Soft Neutral
Soft Neutral — warm editorial
Warm off-white page background with quiet gray cards and restrained teal.

### 03 Analytics Blue
Analytics Blue — classic BI dashboard
Cool pale-blue canvas, white content panels, blue primary action color.

### 04 Teal Mint
Teal Mint — modern product UI
Very light mint background with teal accent and clean white surfaces.

### 05 Dark Developer
Dark Developer — focused dark mode
Charcoal canvas, slate surfaces, cyan-teal accent. Strongly different from the light options.

### 06 Indigo Lavender
Indigo Lavender — modern creative SaaS
Pale lavender canvas with indigo action color; distinctive but still restrained.

## Background color quick comparison
- Minimal Light: `#FFFFFF` — pure white
- Soft Neutral: `#F7F5F0` — warm off-white
- Analytics Blue: `#F1F5FA` — pale blue-gray
- Teal Mint: `#F0F8F7` — pale mint
- Dark Developer: `#111820` — charcoal
- Indigo Lavender: `#F6F5FC` — pale lavender

These themes use the palette's teal/blue/indigo direction as accents; status and chart colors should still be paired with labels or icons, not color alone.
